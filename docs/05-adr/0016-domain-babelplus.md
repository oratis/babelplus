# 0016 · 裁决：域名统一使用 babel.plus，不执行五池采购

> 日期：2026-08-31 · 性质：**架构裁决** · 状态：**已批准**（2026-08-31，用户裁决）
> 事实基线：[0010](0010-domain-strategy.md)（提案，本文否决其采购与池划分，**保留其全部实测事实**）；
> `babel.plus` 归属已确认（2026-08-25，用户：项目所有者自己的域名；HiChina/阿里云注册，
> 2023-01-11 → 2027-01-11，NS `dns13/dns14.hichina.com`）；
> GTS 证书实测（2026-08-21，[evidence/gcp-inventory-20260821 §2](../evidence/gcp-inventory-20260821/)）。
> 关联：[0001](0001-cloudflare-tos-risk.md)、[0002](0002-notification-channels.md) §5、
> [0003](0003-web-hosting-and-reachability.md) §3.2、[0004](0004-transport-hardening.md) §3.4、
> [0010](0010-domain-strategy.md)（被否决的提案）、[issue #24](https://github.com/oratis/babelplus/issues/24) §2.2/§2.4
> 裁决人：项目所有者（2026-08-31，原话「决策就用 babel.plus」）；本文由接手方整理登记。

## 1 · 裁决

1. **`babel.plus` 是本项目唯一的服务主域名。** 子域规划：`web.`（用户面板）、`api.`（用户 API
   与订阅下发）、`admin.`（管理面，仅作 GCLB+IAP 的证书主机名）；后续 `docs.` 等按需增设。
2. **[ADR 0010](0010-domain-strategy.md) 的五池采购不执行**（状态改「已否决」）。
   随之不采用的还有：中性命名规则、暗池、注册商分散（R4/R5）、MAIL 独立域名。
3. **`babel.plus` 从「品牌域名」升格为「基础设施」**：适用 0010 §8.3 的永久续费纪律 ——
   一旦进过订阅 URL / 客户端配置 / 节点名，**不允许过期**（过期被抢注 = 对方可给所有
   还在轮询老地址的客户端下发任意节点配置）。

## 2 · 理由（用户裁决，此处登记而非论证）

- **已持有、零采购、零命名工作。** 0010 的首年 $67–74 采购、商标检索、校验脚本、
  两注册商账号纪律全部免去。
- **品牌一致。** 邀请链接、订阅文件名（`subscription.go:61` 的 `filename*=UTF-8''babel.plus`）、
  邮件发件域从此指向同一个名字 —— 0010 §2.5 登记的「订阅名里印一个不打算使用的 TLD」
  一致性问题因本裁决消解。
- **规模前提。** 邀请制、几十人。0010 自己的失效条件 5 写明「用户规模离开邀请制时其
  许多裁决要重做」—— 同一前提反向适用：在这个规模上，多域名体系的运维成本先于收益到来。
- **一个真实的技术收益**：`web.` 与 `api.` 同注册域名 = **same-site**，cookie 会话成为可能，
  0010 代价 7（跨站被迫把 token 放 JS 可读存储、对 XSS 持续暴露）被消解。

## 3 · 继续成立的硬约束（换域名决策改不掉的）

1. 🔴 **面向中国用户的入口必须钉 Let's Encrypt**（ADR 0004 §3.4，2026-08-21 实测：
   `*.run.app` 证书链是 `O=Google Trust Services`，GTS 在中国触发 IP 级单向丢包）。
   **`web.` / `api.` 不许直接做 Cloud Run 域名映射**（那就是 Google 托管证书）——
   必须经一层能出 LE 的托管/代理（GitHub Pages / Netlify 实测 LE，或 GCLB+自管 LE）。
   选型即 roadmap **B9 剩余**，仍未做；0010 §7.3 的七项上线闸门对任何反代路线照样适用
   （订阅 token 的第三方日志暴露、CDN 缓存键、XFF 限流桶不坍缩）。
2. **CAA 钉 LE 现在真正可行**：`babel.plus` 的 NS 在阿里云（非 Cloudflare），
   不受 0010 §2.4「CF 自动把 `pki.goog` 加回 CAA」的问题影响。应尽早加
   `CAA 0 issue "letsencrypt.org"`。⚠️ 若未来把 zone 迁到 CF，这条保护随之失效。
3. **管理面准入路线不变**（issue #24 §2.2）：`admin.` 只作 GCLB+IAP 的证书主机名，
   GTS 证书对管理员无害（过 IAP 本来就要先过 `accounts.google.com`，必然自带出网通道）。
4. **0010 的实测事实全部保留**：平台可达性与签发者数据（GH Pages 8.9%/LE、Netlify 25.8%/LE、
   Vercel 出局）、CF Universal SSL 无契约钉 LE、`.plus` 续费 $43.77/年。数据不因裁决方向改变。

## 4 · 对 0010 各组件的落点

| 0010 组件 | 落点 |
|---|---|
| 五池采购（$67–74）+ 十步清单 | **不执行** |
| 中性命名八条 + 校验脚本 | 不适用 |
| R1 跨故障域不共享主域名 | 🔴 **明知放弃**（见代价 1） |
| R2 同故障域用子域 | 保留（现在全项目就是一个故障域） |
| R4/R5 注册商与平台分散 | 域名侧失效；**平台侧仍有效**（web 的多平台镜像仍可做，只是共享主域名） |
| 「今天买今天不发布」纪律 | 转化为：**新子域进订阅 URL / 节点名前必须过一次裁决**（发布仍不可逆） |
| 暗池 | 不建（单域名无暗池可言，见代价 2） |
| MAIL 独立域名 + 信誉预热 | 改为在 `babel.plus` 上配 SPF/DKIM/DMARC（见代价 4） |
| CERT 池（节点 Hysteria2 证书） | **未解决**：用 `babel.plus` 子域签证书会把节点主机名写进 CT 日志（0010 §9.3），留待第一台节点上线时裁决 |
| T1 / T2 两个 $0 测试 | **保留价值**：T1 若证伪 GTS 有害论，`api.` 可直连 Cloud Run，B9 选型归零成本 |
| 品牌不进域名 | 反向：品牌 = 域名（见代价 5） |

## 5 · 执行清单

1. 【用户】阿里云侧：确认 `babel.plus` **自动续费**开启，建议一次续多年（到期 2027-01-11）——
   它现在是基础设施，不是一笔可弃资产。
2. 【用户】阿里云 DNS 加 `CAA 0 issue "letsencrypt.org"`（§3.2；给 `admin.` 走 Google 托管证书
   需同时允许：再加一条 `CAA 0 issue "pki.goog"`，或 CAA 只加在 `web.`/`api.` 子域上）。
3. `admin.babel.plus`：GCLB + IAP + `BP_ADMIN_IAP_AUDIENCE`/`BP_ADMIN_TOTP_ENC_KEY`（issue #24 §2.2）。
4. `web.` / `api.`：**等 B9 与 ADR 0003 托管选型落定后再建解析**，不许直接 CNAME 到 Cloud Run（§3.1）。
5. 邮件：ESP 账号注册后在阿里云配 SPF/DKIM（发信子域建议 `mail.babel.plus` 或根域，由 ESP 引导）。
6. `subscription.go:61` 的 `filename*=UTF-8''babel.plus` **保持不动** —— 0010 §2.5 的两种情形都已消解。

## 6 · 失效条件

1. **用户规模离开「邀请制 + 几十人」** —— 单域名同生共死的代价重估，0010 的采购部分是现成的重启方案。
2. **`babel.plus` 被封或被处置** —— 无镜像、无暗池，恢复 = 从零采购 + 发布 + 邮件广播（天级）。
   **发生一次即应重启 0010 的采购部分**，且那时是在事故中做采购。
3. **阿里云（注册商/DNS 双重角色）对域名采取合规处置** —— 同上，更急（见代价 3）。

## 7 · 代价

> ⚠️ 这一选择的代价，必须留在记录里而不是被措辞掩盖：
>
> 1. 🔴 **全项目一个注册域名 = 一个故障域。** ADR 0003 §3.2 与 0010 R1 被明知放弃：
>    `web.` / `api.` / `admin.` / 邮件同生共死，封锁粒度若在主域名级，一次封锁全灭，
>    且邮件（唯一失联恢复通道，ADR 0002）与被封对象共享命运 —— 恢复通道在最需要它的
>    那一刻最可能不可用。
> 2. **「域名失联恢复 ≤ 30 分钟」全线不成立**（0010 只是对 API 池不成立，本裁决对所有面
>    都不成立）。真实恢复时长 = 新域名采购 + 发布 + 邮件广播，以天计。产品口径不得再
>    引用 30 分钟数字。
> 3. **注册商与 DNS 都在阿里云（中国大陆法域）。** zone 内容对服务商可见，而本项目的
>    性质与大陆监管环境冲突 —— 处置风险真实存在且不可量化。0010 的命名与注册商纪律
>    想规避的正是这个形状；本裁决接受它。实名注册信息将项目与所有者身份直接关联，匿名性为零。
> 4. **发信域与主站域不再分离**（ADR 0002 §5 的要求落空）：主域名出任何事（封锁、信誉、
>    处置），发信信誉一起受损。无已知缓解。
> 5. **品牌 = 域名**：域名被封即品牌死名，不可换壳重来。
> 6. **续费成本**：`.plus` 续费 $43.77/年（`.org` 的 3.7 倍），且按第 1 条纪律永久不许过期。
