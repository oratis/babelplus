## 2 · 定位：能卖的不是「便宜」，是「AI 可用 + 不跑路 + 有售后」

市场按 GB 的价格（[acquisition-channels §2](../01-research/acquisition-channels.md)）：

| 参照            | 元/GB      | ¥3/GB 相对倍数 |
| ------------- | --------- | ---------- |
| 中转机场月付        | 0.07–0.20 | 15–43×     |
| 不限时流量包中位      | 0.35–0.50 | 6–8.6×     |
| IPLC 专线       | 0.40–0.80 | 3.8–7.5×   |
| 我们的出口变动成本 `c` | 0.81      | 3.7×       |

**¥3/GB 是另一个数量级，不是「稍贵」。** pricing §3.5.8 已证明按竞品价卖每 GB 净亏，本文不再重算。
所以用户画像必须窄：

| 卖给谁                                    | 月用量     | 月支出    | 他们为什么不买 ¥10/100GB 的机场                                |
| -------------------------------------- | ------- | ------ | ---------------------------------------------------- |
| **AI 工具用户**（Claude / ChatGPT / Cursor） | 3–15 GB | ¥9–45  | 被限速、被风控、机场 IP 被 AI 服务拉黑；product-brief §3 把 AI 列为第一场景 |
| **开发者**（GitHub / 包管理 / 云控制台）           | 5–20 GB | ¥15–60 | 需要稳定不需要流媒体；GCP 出口对开发工具友好                             |
| **被跑路伤过的人**                            | 任意      | —      | 17zz 名单 2024–2026 共 20 家跑路，「不跑路」是可以卖的                |

**不卖给谁**：流媒体、大文件下载、多设备家庭共享。这不是放弃，是 product-brief §3 与 pricing §2.1 原则 3 的既有立场。

**文案立场**（与 product-brief §3 一致）：不承诺流媒体解锁、不写「无限流量」、不写「永久」、规则全部写在商品页。
[acquisition-channels §2.2](../01-research/acquisition-channels.md) 指出陷阱条款是市场常态 —— **规则透明本身是卖点**。

## 3 · ¥3/GB 的成本核算：每一格都可当场复算

### 3.1 参数

全部引自 pricing §3.5.1，本文一个参数都没新设：

```
c     = $0.121 / GiB          出口变动成本（Standard 目录价 $0.11 × 计量系数 1.10）
f_cap = $3.2916 / 人 / 月      固定成本分摊上限
FX    = 7.15
地板   = 1.20×
s     = 闲鱼平台费，按 0.6% 计（🔴 待核实：闲鱼 2024-09 起对达标卖家收「软件服务费」，比例与门槛需查官方规则）
```

**单位约定**：商品页写「G」，系统按 **GiB** 发放（pricing §2.1 原则 6：配额单位用 GiB）。
多给 7.37% 是变动成本上的让利，换来对账零换算。下表全按 GiB 算成本。

### 3.2 全摊口径（每个 30 天包扛一份 `f_cap`）

| SKU            | 售价      | 收入 \$  | 变动 \$ | 固定 \$ | 总成本 \$ | **覆盖**    | 判定                                         |
| -------------- | ------- | ------ | ----- | ----- | ------ | --------- | ------------------------------------------ |
| 3G / 3 天 体验    | ¥9      | 1.259  | 0.363 | 3.292 | 3.655  | 0.34×     | ❌（见 §3.4，按营销费用记）                           |
| 10G / 30 天     | ¥30     | 4.196  | 1.210 | 3.292 | 4.502  | **0.93×** | ❌ **不挂**                                   |
| 12G / 30 天     | ¥36     | 5.035  | 1.452 | 3.292 | 4.744  | 1.06×     | ❌                                          |
| **15G / 30 天** | **¥45** | 6.294  | 1.815 | 3.292 | 5.107  | **1.23×** | ✅ 入口 SKU                                   |
| **20G / 30 天** | **¥60** | 8.392  | 2.420 | 3.292 | 5.712  | **1.47×** | ✅ 主推 SKU                                   |
| 30G / 30 天     | ¥90     | 12.587 | 3.630 | 3.292 | 6.922  | 1.82×     | ✅ 但**不挂**：比官网轻量档 ¥72/30 GiB 贵 25%，用户会自己去官网 |

复算示例（15G）：`45 / 7.15 = 6.294`；`15 × 0.121 + 3.2916 = 5.107`；`6.294 / 5.107 = 1.232`。平台费 0.6% 使 15G 降到 1.225×，仍在地板上。

**为什么 10G ¥30 救不回来**：兑付率是唯一能压变动成本的变量，但把它压到 0（一字节不用）总成本仍是 \$3.29，覆盖 1.27× —— 而兑付 0.6 时是 1.04×、0.4 时 1.11×，都过不了 1.20×。
**小包的问题不在每 GB 毛利，在于它扛不动一份固定成本。** 要挂 10G ¥30，只有两条路：
（a）把它当边际用户不摊 `f`（§3.3），（b）改 ¥3.9/GB 破坏「¥3/GB」这个口径。本文两条都不推荐，把选择权留给用户。

### 3.3 边际口径（闲鱼买家不摊 `f`，只覆盖变动成本）

| SKU          | 覆盖（变动）    |
| ------------ | --------- |
| 任意 ¥3/GB SKU | **3.47×** |

这个口径成立的条件：闲鱼买家使用的节点容量是订阅用户已经付过钱的。它在 `N` 小于容量上限时为真，
在需要加第二台节点时为假（pricing §3.5.7：P3 稳态栈本身需要 ≥ 16 名付费用户作前置）。
**建议记法**：闲鱼订单在 `f_actual = F / N` 里**计入 N**（它们是真实付费人头，摊薄所有人的 `f`），
但 SKU 定价按 §3.2 全摊口径守地板 —— 两边都保守。

### 3.4 体验包按营销费用记，不按 SKU 记

3G / 3 天 / ¥9：变动成本 $0.363，收入 $1.259，**变动口径 3.47× 是赚的**；全摊口径不成立是因为它不占一个「用户月」。
规则：每账号一次、只能通过兑换码获得、3 天到期不顺延。它替代的是 pricing §3.4 明令不做的**免费试用** —— 付费体验不是免费试用，且市场已有先例（魔戒 ¥1/1GB、可信云 ¥2/3GB/3 天）。

### 3.5 清零 + 续买顺延

| 规则       | 内容                                            | 成本影响                                                                                                                            |
| -------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 有效期      | 30 天，**自兑换激活起算**，不是自购买                        | 用户手里的未激活码不占容量                                                                                                                   |
| 到期       | 清零，订阅返回空列表 + 伪节点告知（user-journey 既有机制）         | —                                                                                                                               |
| **续买顺延** | 到期前兑换下一个码：剩余流量并入新周期，**顺延上限 = 一个包的量**；到期后兑换不顺延 | 最坏情形 20G 包实际发 40 GiB：变动 $4.84 + 固定 $3.29 = $8.13 → 1.03×。⚠️ **这是本文唯一一格破地板的组合**，条件是「上一周期一字节没用 + 本周期全用完」，属于罕见极端；常态（兑付 60%）是 1.77× |
| 叠加       | 激活中再兑换 = 顺延规则；不允许两个包同时计时                      | 简化 ADR 0013 的升级折抵：兑换码路径**没有折抵**，只有顺延                                                                                            |

顺延不是慷慨，是把「清零」这个最大的询盘异议（市场默认不限时）换成一个成本有界的承诺。

### 3.6 与官网套餐的关系

| <br /> | 闲鱼 20G ¥60                        | 官网轻量 ¥72 / 30 GiB / 2 设备 |
| ------ | --------------------------------- | ------------------------ |
| 元/GiB  | ¥3.00                             | ¥2.40                    |
| 差价的用途  | 闲鱼是**收款通道**：支付宝一键付、无 USDT 门槛、平台担保 | 官网是**更便宜的续费路径**          |

**漏斗**：闲鱼首单 → 兑换注册 → 面板内看到「续费去官网更便宜」→ 第二个月转官网月付。闲鱼的角色到此为止。
这条漏斗成立的前提是官网**能收钱**（ADR 0012 未批、链上扫描器未配置）——否则用户只能一直回闲鱼买码，而每一笔都在累积 §1 第 0 条的证据链。

### 4.2 渠道 C · 扩展与浏览器

**扩展：做，第二期，走「服务端 HTTPS 代理入站 + MV3 扩展」**（acquisition-channels §5.2 方案 ①）：

| 项     | 裁决                                                                                                                                                     | 理由                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| 商店    | **Edge Add-ons 主推**，Chrome Web Store 同步上架给海外 / 已有梯子的用户，官网 zip 兜底                                                                                       | CWS 大陆不可达；Edge 可达且已有代理类扩展在售；Edge 政策 1.8 允许第三方支付卖订阅                            |
| 上游    | 节点新增 **HTTPS 代理入站**（Caddy `forwardproxy` 带 `probe_resistance` 回落到真网站，或 Xray `http` inbound + TLS + accounts），每用户 Basic 凭据由订阅 token 派生                  | 扩展只能设 HTTP(S)/SOCKS 代理；SOCKS5 在 Chrome 无认证；Native Messaging 方案要装原生程序，等于做桌面客户端 |
| 存活性   | **需实测**：1–2 个测试域名跑两周对照 REALITY；按用户组分域名控制爆炸半径；纳入 [ADR 0010](../05-adr/0010-domain-strategy.md) 域名池                                                      | Chrome 裸 HTTPS 代理 = 无 padding 的 NaiveProxy，抵抗力弱于 REALITY                      |
| 计量    | 🔴 **待核实**：HTTPS 入站的每用户流量能否进现有 UniProxy 计量路径（v2node 只认它支持的节点类型）。若不能，需要一条独立的流量上报 → `stat_user_server` 通路，否则扩展流量**不扣配额**，就是 pricing §2.1 原则 5 之外的第三个失效窗口 | 这是本方案最大的工程不确定性                                                                |
| 扩展内售卖 | 扩展内只做「登录 / 状态 / 一键连接 / 剩余流量 / 去官网充值」；**付款跳官网**                                                                                                         | CWS Payments 2021 已关；Edge 允许第三方支付                                             |
| 权限    | 只申请 `proxy` / `webRequest` / `webRequestAuthProvider` / `storage`，**不要** **`<all_urls>`** **内容脚本**                                                     | Urban VPN 因采集数据被曝光；FreeVPN.One 因偷截图被下架                                        |
| 工作量   | 4–8 周到可售（扩展 2–3 周 + 入站 1 周 + 上架 1–2 周）                                                                                                                 | acquisition-channels §5.5                                                     |

**浏览器：不做。** 三条理由，任一条都够：

1. Chromium fork 对 1–2 人不可行（每 4–6 周 rebase 数个工作日 + 32 核构建机）；Electron 壳是客户端不是渠道。
2. 「自带节点的浏览器」是 acquisition-channels §4.1 罪名最直接的物证；国内没有成规模的先例，凡出现即下架。
3. 签名与误报是持续成本：EV 证书已不再绕过 SmartScreen；Xray 二进制被 Defender 误报且上游 not planned。

**可选副产品**：扩展做完后，「几 MB 启动器 + 随包 sing-box + 拉起本机 Chrome/Edge `--proxy-server`」1–2 周可做，
给「不会装扩展」的用户；它复用 REALITY 节点，不需要 HTTPS 入站。**留待阶段 B 之后评估，不进本文排期。**

## 7 · 代价

> ⚠️ 这一选择的代价，必须留在记录里而不是被措辞掩盖：
>
> 1. **裁决 0 把最重要的问题推回给用户，本文没有替他做。** 代价是：如果用户不批 A0，本文 §3–§6 全部是纸上作业；如果批了，product-brief §4 的三条含义（注册受控、规模有上限、收款服务于成本分摊）**同时失效**，且失效的不只是文档，是 pricing §3.5.7 里「P3 稳态栈需 ≥ 16 人」那类以小规模为前提的全部运维准入规则。
> 2. **不挂 10G ¥30 = 放弃闲鱼上最有搜索竞争力的价位。** 闲鱼是价格排序市场，¥45 起步会让询盘量显著低于 ¥30 起步（幅度**无数据**）。换来的是每个 SKU 都守住 1.20× 地板。若 A2 基线显示询盘量不足以产出 20 人，这条裁决应在 A3 重开。
> 3. **续买顺延引入了本文唯一一格破地板的组合**（§3.5：上周期零使用 + 本周期全用完 = 1.03×）。它是有界的（上限一包）、罕见的、且对账可见的（顺延量写进订单）；但它成立的前提是「兑付率不会系统性地接近 100%」——如果闲鱼买家普遍是重度用户，这条要撤。
> 4. **扩展的 HTTPS 入站是第二种传输，它的封锁面比 REALITY 大。** 存活期未实测；一旦被封，扩展用户整体失联而 REALITY 用户不受影响 —— 这意味着两类用户的可用率 SLO（ADR 0014）要分开写，运维面翻倍。
> 5. **不做浏览器 = 放弃「全球网络互联浏览器」这个用户明确提出的产品形态。** 理由在 §4.2，三条里最硬的是法律物证那条。若用户坚持，最便宜的替代是 §4.2 末段的启动器变体，它不是浏览器，也不该以浏览器的名义宣传。
> 6. **拒绝测评站 aff 与免费试用 = 放弃行业里最有效的两种起量手段。** 代价是增长慢。这是 pricing 的地板纪律与 product-brief 的规模上限共同要求的，本文没有新增约束，只是把它们的后果写出来。
> 7. **多给 7.37%（卖 G 发 GiB）** 是每单变动成本上确定的让利，换来对账零换算。20G 包上是 \$0.18/单。

## 8 · 这次没有解决的

* [ ] **A0 的 ADR 没有写。** 它需要用户对运营主体、收款账户与身份暴露的取舍先表态，本文只把判例与门槛摆出来。

* [ ] **闲鱼平台费的比例与门槛未查**（§3.1 按 0.6% 记，待核实官方规则）。它对 15G 覆盖倍数的影响是 −0.007×，不改变任何判定，但要落实。

* [ ] **闲鱼上「稳定梯子」类商品的实际成交价与询盘量无任何数据。** 这只能靠 A2 实测得到；本文 §3 的 SKU 阶梯在 A3 之前都是设定值。

* [ ] **兑换码的外部对账口径未定**：闲鱼成交在系统之外，系统只在兑换时知道；`external_ref` 存闲鱼订单号靠人工填。批次「已售出 / 已兑换 / 已过期」三态的月度对账报表未设计。

* [ ] **ADR 0013 的兑换路径增补未写**（§5 F3）：无折抵、无退款、顺延规则、与加油包「必须有生效订阅」规则的关系。

* [ ] **HTTPS 入站的每用户计量能否进 UniProxy 路径**（§4.2）—— 这是阶段 B 的第一个技术门槛，未核实。

* [ ] **HTTPS 代理在大陆的存活期未实测**（阶段 B 前置，两周对照实验）。

* [ ] **`docs.*`** **的百度收录与大陆可达性未实测**（渠道 D2 的有效性依赖它）。

* [ ] **官网收款闭环（F8）不在本文范围**，但 §3.6 的「闲鱼首单 → 官网续费」漏斗没有它不闭合；在它闭合之前，闲鱼是唯一收款通道，每一笔续费都在累积 §1 第 0 条的证据链。

* [ ] **QQ 邮箱送达率**是闲鱼渠道的成交率上限，目前是零数据（ESP 未接）。
